# MathForge

A math practice generator that runs in the browser. Pick a topic, a difficulty
and how many problems you want, and MathForge writes a fresh set with answers
and worked steps.

Plain HTML, CSS and JavaScript: no build step and no dependencies.

## Topics

| Topic | Covers |
|---|---|
| Arithmetic | Addition, subtraction, multiplication |
| Fractions, Decimals, and Percents | Number sense |
| Pre-Algebra Equations | Solving equations |
| Algebra I/II | Algebra |
| Geometry | Geometry |
| Trigonometry | Trig |
| Precalculus | Precalculus |
| Calculus I | Limits, derivatives, integrals |
| Calculus II | Series, techniques, polar |
| Calculus III | Vectors and multivariable |
| Mixed Challenge | A mix from the full range |

## Features

- Easy, Medium and Hard difficulty
- 1 to 12 problems per set
- Toggle worked steps and answers on or off
- Print a problem set

## Running it

Open `index.html` in a browser. That's it.

## Files

| File | What it does |
|---|---|
| `index.html` | Page layout and controls |
| `styles.css` | Styling |
| `script.js` | Topic list and the problem generators |
